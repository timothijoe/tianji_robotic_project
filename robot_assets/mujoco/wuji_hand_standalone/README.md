# Official Wuji Hand standalone model

Unmodified left- and right-hand MuJoCo subset vendored from
`https://github.com/wuji-technology/mujoco-sim`, submodule
`https://github.com/Wuji-Technology-Co-Ltd/wuji_hand_description.git` at commit
`63d2785932eb5b91523e44222f5d0bcffbce1e74`.

Imported 2026-08-03. The `mjcf/left.xml` and `mjcf/right.xml` models and their
corresponding `meshes/left` and `meshes/right` dependencies, plus the upstream
MIT license, are included. Integration code is not copied.

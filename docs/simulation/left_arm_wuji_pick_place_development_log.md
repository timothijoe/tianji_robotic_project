# 左臂 + Wuji Hand 抓取放置开发日志

日期：2026-07-31  
分支：`feature/left-wuji-pick-place`  
基线：`58ec9ab`

## 目标与边界

阶段 A 的目标是让左臂和 Wuji Hand 在 MuJoCo 中抓取一个自由 5 cm 方块，
抬升至少 0.08 m、横向搬运至少 0.15 m，并释放到目标区。实体机器人代码保持
不动；不使用 weld、equality、mocap、方块瞬移或运行时附着。阶段 B 的
“左手扶持蔬菜、右臂切菜”只保留接口边界，本轮没有实现。

## 实现历程

1. 增加自由方块、目标区、左掌 TCP 和模型名称检查。
2. 将原先绑定右臂的 FK/IK/路径求解改为显式选择左右臂，并确保临时求解后
   完整恢复 MuJoCo 状态。
3. 为左臂增加独立位置目标、关节状态和掌心位姿接口；右臂目标保持隔离。
4. 增加接触抓取监测：统计手—方块接触、判断相对接触法向、检查方块速度和
   手指执行器力，并要求不同手部刚体连续 0.55 s 形成相对接触。
5. 实现预抓取、接近、闭合、稳定、抬升、搬运、下降、释放、撤离和完成阶段。
6. 增加规划掌心、实际掌心和实际方块三条轨迹，以及 `pick-place` CLI。

## 主要问题与解决

### 方块在闭合或抬升时侧向弹出

最初直接使用 Wuji 手的高精度渲染网格作为碰撞网格，接触点会出现较深穿透，
闭合后把方块挤出。对照下载的
`wuji-description/hand/body-with-soft/mjcf/left_simplified.xml` 后，将指节
碰撞代理改为胶囊体，并保留原视觉网格和 20 个关节。指尖保留独立球形接触垫。

### 抓取中心使用了错误坐标系

早期把官方方块中心 `(0.060, 0.004, 0.075)` 当成掌心 TCP 坐标；实际该值是
掌骨 body 坐标，而本项目 TCP 在掌骨局部 `z=0.07 m`。这使方块高出指笼约
70 mm。修正坐标含义后，再通过无窗口扫描得到当前 TCP 抓取偏移
`(0.05, -0.04, 0.005) m`。

### 夹具遮挡掌心朝上的进入路径

侧向夹持在抬升中容易滑脱。最终将手掌绕局部 Z 轴旋转 60°，使掌心接近朝上，
由重力把方块压入指笼。抓取台和目标台使用独立碰撞类别，只支撑方块而不与
机器人碰撞；方块—手碰撞始终启用。这是任务夹具简化，不是隐藏抓取。

### 从零位到预抓取位会扫过方块

左臂从默认零位执行长关节插值时会穿过抓取区。任务现在在 reset 后将左臂
初始化到求解出的预抓取关节位，再从该位执行连续 Cartesian 接近。方块状态
没有被修改。

### Viewer 正常完成后退出码 139

最小复现显示问题与抓取代码无关：完整 MuJoCo 场景的被动 Viewer 在
`Handle.close()` 返回后，其 `_launch_internal` 线程仍可能清理资源，而主线程
已进入 GLFW `atexit`。`RightArmRobot` 现在记录 Viewer 线程并在关闭后 join，
从而消除析构竞态。最小 Viewer 和完整慢速抓取均以退出码 0 结束。

### 目标台穿透被较低的砧板高度掩盖

最初验收只用方块中心高度减去固定半边长，并与 chopping board 比较；这既
漏掉高出的目标台，也忽略方块旋转后的世界坐标包络。现在每个样本直接记录
MuJoCo 方块—任务支撑面的 `contact.dist`，运行期和最终验收统一要求穿透不
超过 2 mm；同时提高两个 20 g 方块支撑台的接触刚度，并略微提高下降终点。

### 审查发现成功条件不完整

最终结果现在同时检查抬升、搬运、目标平面误差、支撑面穿透、释放后手部
零接触、连续低速和 0.25 s 独立静置。抬升后或搬运中失去接触/高度会立即
中止；右臂命令目标必须完全不变，实际关节状态允许原生位置执行器产生
0.005 rad 以内的稳态偏差。

## 最终参数

- 方块初始中心：`(0.62, 0.22, 0.403) m`
- 目标中心：`(0.62, 0.02, 0.379) m`
- 方块：边长 `0.05 m`，质量 `0.02 kg`
- TCP 抓取偏移：`(0.05, -0.04, 0.005) m`
- 掌心附加旋转：局部 Z 轴 `60°`
- 手指稳定等待：连续 `0.55 s`
- 方块稳定速度阈值：线速度 `0.04 m/s`、角速度 `1.5 rad/s`
- 手指模拟力终止阈值：`1.0`（仅为模型内未标定数值）
- 抬升高度命令：`0.10 m`
- 目标半径：`0.045 m`
- 主要阶段时长：预抓取 `5.0 s`、接近 `2.0 s`、闭合 `2.5 s`、
  抬升 `3.0 s`、搬运 `4.0 s`、下降 `3.0 s`

一次最终无窗口验收的指标为：

- 最大抬升：`0.083 m`
- 水平位移：`0.209 m`
- 最终目标平面误差：`0.028 m`
- 最大手指执行器力：`0.075`

  修复线程析构竞态后正常退出。
- `protected-files.sha256`：全部通过。

## 已知限制与阶段 B

- 当前接触摩擦、碰撞代理和 effort 未经实体 Wuji Hand 标定。
- 任务夹具对机器人关闭碰撞，因此不能用于评估手—夹具安全距离。
- 当前任务初始化到预抓取位，不包含从任意左臂姿态到抓取区的全局避障规划。
- 阶段 B 需要新增左手持物健康状态、右刀下降许可、双臂同步 abort 和刀具净空；
  导纳控制只作为后续备选，不在本提交中。

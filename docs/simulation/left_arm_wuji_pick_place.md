# 左臂 + Wuji Hand 抓取放置

本功能是仿真阶段 A：左臂从任务初始位接近一个自由 5 cm 方块，Wuji Hand
闭合并依靠 MuJoCo 接触和摩擦持物，随后抬升、横向搬运、下降、释放并撤离。
当前验收要求为抬升不少于 0.08 m、水平搬运不少于 0.15 m，并在目标区域内
稳定落下。成功还要求方块不穿透任务支撑面、释放后不再接触手、末速度低于
0.02 m/s，并独立静置至少 0.25 s。

## 运行

安装仿真环境后执行：

```bash
.venv/bin/twin-sim pick-place --headless
.venv/bin/twin-sim pick-place --slow --final-hold 15
```

第一条命令运行无窗口回归并打印成功状态、阶段、最大抬升、水平位移、最终
目标误差和最大手指执行器力。第二条命令打开 MuJoCo Viewer，以实时速度播放，
结束后保留 15 秒供检查。

Viewer 中的轨迹标记为：

- 蓝色：规划掌心位置；
- 青色：实际掌心位置；
- 橙色：方块实际位置；
- 绿色：场景中的放置目标区域。

`--slow` 只改变播放节奏，不切换控制器。机械臂和手指仍使用 MuJoCo 原生
`position` actuator。

## 实现边界

- 方块使用 free joint，场景中没有 weld、equality、mocap 或运行时附着。
- 持物依靠手指碰撞代理、接触力、摩擦和重力；释放后方块独立稳定至少
  0.25 秒。
- 稳定抓取要求至少两个接触点来自不同手部刚体，且接触法向相对。
- 左手碰撞代理按官方 `wuji-description` 的简化思路使用胶囊体，视觉网格和
  20 个关节保持不变。这样避免把高精度渲染网格直接用于碰撞时产生的深穿透。
- 抓取台和放置台只与方块发生碰撞，机器人可穿过任务夹具。这是为了避免
  夹具遮挡掌心朝上的抓取路径；方块与手之间的碰撞没有过滤。
- 任务开始时左臂直接初始化到预抓取位，避免从零位扫过方块。方块没有被
  重置、瞬移或附着到手上。
- 仿真 effort 未经过实体手标定，当前数值不能直接当作牛顿或硬件安全阈值。
- 右臂命令目标要求逐元素不变；由于原生位置执行器在仿真步进中的稳态误差，
  右臂实际关节状态使用 0.005 rad 容差验收。

这些命令仅用于 MuJoCo，不能发送到实体机械臂或实体 Wuji Hand。

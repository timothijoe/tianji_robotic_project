# 双臂猫爪倒手切菜开发日志

日期：2026-07-31
分支：`feature/left-wuji-pick-place`

## 目标

右臂持刀对固定方块演示 5 次下切，左臂和 Wuji Hand 以猫爪姿态护住方块，
每次右刀抬起并到达下一刀安全位后，左手后退 0.02 m。阶段 A 使用确定性
状态机；阶段 C 只预留 `SafetyCoordinator` 接口。

## 实现记录

1. 增加默认隐藏、无关节的固定红色方块；任务启动时只在当前 MuJoCo 模型
   实例中显示它，并隐藏抓取放置使用的自由方块、绿色目标区和两个灰色台。
2. 在 Wuji Hand 中指第二指节增加 `left_guard_knuckle_site`，作为刀手距离的
   几何参考点。
3. 增加 20 关节 `CAT_PAW_RAD`：拇指向掌内收，另外四指的近端与远端关节
   弯曲，形成半握拳护手姿态。
4. 复用巡线切菜的刀具姿态和横向切点，但将整条刀轨迹提高到固定方块顶部，
   避免沿用砧板高度后把刀硬压入方块。
5. 左手使用独立左臂 IK 生成 4 段笛卡尔倒手轨迹；右刀下切时左手目标锁定，
   左手倒手时右刀目标锁定。
6. 安全距离使用护手点到旋转刀片 box 表面的最近距离，不使用 TCP 或刀片
   中心距离。
7. 增加蓝、青、紫、黄四类 Viewer marker，以及刀数、阶段、距离和许可状态
   overlay。

## 已解决问题

### 原切菜轨迹会进入固定方块

原 `line-chop` 以砧板表面作为接触高度；固定方块高 0.10 m，直接复用会让
刀具穿过方块。预检现在按“方块顶面－砧板顶面”整体抬高刀轨迹，并增加
小量跟踪余量。方块仍为刚性固定物体，不实现切分或变形。

### TCP 距离不能代表刀手安全距离

刀具 TCP 位于刀柄/工具坐标处，与刀面有明显偏移。安全协调器现在把护手点
变换到 `right_knife_blade` 的局部坐标，计算到旋转 box 表面的最近距离。

### 双臂移动许可容易混在一条轨迹中

状态机明确分成 `CUT_DOWN`、`KNIFE_UP` 和 `HAND_SHIFT`。右刀在
`KNIFE_UP` 中先抬起并横移到下一刀安全位；随后右臂保持目标，左手才执行
倒手。这样阶段 C 可以替换许可策略而不重写轨迹。

## 验证与限制

定向测试 27 项通过；全量测试 141 项通过，仅保留一条既有切菜接触力 warning。
无窗口集成运行完成 5 刀、4 次倒手，总目标位移 0.08 m，实测最小刀手距离
约 0.023 m；实体机保护哈希全部通过。Viewer 首次逐控制周期刷新 overlay，
导致播放耗时数分钟；将文本和 marker 一并降采样到每 10 个控制周期后，完整
动作、3 秒结尾保留和正常退出约 50 秒完成，返回 `success=True`。

当前限制：方块固定且不会变形；猫爪只使用位置控制，不依赖接触力闭环；
刀手保持几何间隙，不模拟第二指节贴刀面；阶段 C 的实时误差恢复和导纳控制
尚未实现；所有命令仅用于 MuJoCo。

# MuJoCo 机械臂力控与剁切 Demo 需求分析

## 1. 文档目的

本文档定义 `cook_ws` 第一版 MuJoCo 力控功能的需求、技术边界、控制架构、接口、安全策略和验收标准，作为后续设计、实现与测试的依据。

参考实现位于：

- `TJ_FX_ROBOT_CONTRL_SDK/contrlSDK100343001`
- `TJ_FX_ROBOT_CONTRL_SDK/kinematicsSDK`
- `TJ_FX_ROBOT_CONTRL_SDK/DEMO_PYTHON`

参考 SDK 用于理解控制模式和 Python 调用方式。第一版仿真控制器不直接依赖厂商动态库，而是在 `cook_ws` 中基于 MuJoCo 重新实现可测试的控制链。

## 2. 第一版目标

为单臂七自由度机械臂实现一个基于关节力矩驱动的 MuJoCo 控制系统，支持：

1. 工具坐标系下的笛卡尔阻抗控制；
2. 工具 Z 轴单方向恒力控制；
3. 非接触轨迹跟踪与接触力控制之间的平滑切换；
4. 参数化的重复剁切动作；
5. 腕部六维力/力矩反馈；
6. 安全保护、运行日志和定量验收。

第一版优先完成独立 Python 控制库和 Demo，不集成 ROS 2 控制接口。

## 3. 非目标

第一版不包括：

- 双臂协同控制；
- 真实蔬菜切断、材料破裂或刀具穿透模型；
- 推切、拉切等水平切削动作；
- 完整六轴混合力/位控制；
- 复杂 GUI；
- 厂商 `kinematicsSDK` 或 `contrlSDK` 动态库绑定；
- ROS 2 topic、service 或 action 封装；
- 真实机械臂部署。

## 4. 场景与模型

### 4.1 基础机器人模型

基础 MJCF 应保留通用机械臂结构，并补充：

- 七个关节力矩 actuator；
- 每个 actuator 的力矩限制；
- 工具安装接口；
- 控制器需要的稳定命名。

基础模型不直接包含砧板和剁切测试环境。

### 4.2 独立剁切场景

新增独立 `chopping_scene.xml`，至少包括：

- 基础机械臂模型；
- 简化刚性工具；
- 腕部六维力/力矩传感器；
- 固定水平砧板；
- 可调接触刚度、阻尼和摩擦参数。

简化工具采用圆柱杆和球形端头。其质量、尺寸、工具中心点及传感器安装位必须参数明确，后续可以替换为刀具或锅铲。

### 4.3 六维力传感器

传感器安装在 `Link7_L` 与独立工具 body 之间的传感截面，不能仅在 `Link7_L` 上添加无物理分隔的 site。

MuJoCo 中使用配对的 force 与 torque sensor，组合成工具坐标系下的：

```text
[Fx, Fy, Fz, Mx, My, Mz]
```

工具 Z 轴为第一版力控轴。正负号约定必须通过模型测试确定，并由控制接口统一为：

```text
正目标力 = 工具沿自身 Z 轴压向接触平面
```

## 5. 控制架构

总体控制链：

```text
笛卡尔关键帧轨迹
→ 轨迹插值与阶段状态机
→ 末端位姿/速度误差
→ 笛卡尔阻抗与工具 Z 轴力控制
→ 期望末端 wrench
→ Jacobian 转置映射
→ 重力/科氏力补偿与力矩限幅
→ 关节 actuator
→ MuJoCo 动力学与六维传感器反馈
```

### 5.1 非接触阶段

全六维采用笛卡尔阻抗控制：

```text
wrench_cmd = Kx * pose_error + Dx * velocity_error
tau_cmd = J.T * wrench_cmd + qfrc_bias
```

其中：

- 平移和旋转使用独立刚度、阻尼参数；
- 姿态误差采用无奇异的旋转误差表示；
- 最终关节力矩必须按模型限制裁剪；
- 必须限制力矩变化率，避免模式切换冲击。

### 5.2 接触阶段

采用混合位置/力控制：

- 工具 X、Y 和姿态继续跟踪笛卡尔轨迹；
- 工具 Z 轴由位置阻抗切换为恒力闭环；
- Z 轴轨迹位置仅作为下探趋势和最大深度约束；
- 最终仍通过 Jacobian 转置映射为关节力矩。

力控制器第一版可采用带限幅、抗积分饱和和低通反馈的 PI/PID 控制。具体控制律和增益在实现阶段通过仿真测试确定。

### 5.3 逆运动学

轨迹生成和安全姿态计算采用 MuJoCo Jacobian 与阻尼最小二乘逆运动学，不链接厂商运动学 SDK。

逆运动学必须包括：

- 奇异点阻尼；
- 最大关节速度限制；
- 关节限位回避；
- 工具姿态保持；
- 收敛检测；
- 失败后停止并报告原因。

实时力矩控制不依赖 IK 输出关节阻抗命令；IK 主要用于初始姿态求解、轨迹可达性验证及必要的参考生成。

## 6. 控制周期

- MuJoCo 仿真步长：`2 ms`；
- 底层阻抗和力控制频率：`500 Hz`；
- 用户轨迹输入频率：`100 Hz`；
- 控制器内部将轨迹平滑插值至 `500 Hz`。

控制循环应监测实际运行周期，并在日志中输出平均频率、最差周期和超时次数。

## 7. 轨迹与状态机

### 7.1 轨迹格式

第一版使用带显式阶段标记的笛卡尔关键帧。每个关键帧包含：

- 时间；
- 工具位置 XYZ；
- 工具姿态；
- 阶段标记。

阶段枚举：

```text
APPROACH
DESCEND
FORCE_HOLD
RETRACT
SHIFT
```

### 7.2 剁切循环

单次循环：

```text
安全高度
→ 沿工具 Z 轴落刀
→ 检测接触
→ 建立并保持目标力
→ 沿原路径起刀
→ X 方向移动
→ 下一次落刀
```

第一版只实现原地垂直剁切，不加入水平推切或拉切。

### 7.3 默认参数

- 剁切次数：`5`；
- 安全高度：砧板上方 `80 mm`；
- 相邻落刀间距：`20 mm`；
- 下降速度：`50 mm/s`；
- 目标接触力：`10 N`；
- 恒力保持时间：`0.5 s`；
- 抬刀速度：`80 mm/s`。

所有参数必须支持 Python API 和命令行覆盖。

## 8. 接触检测与模式切换

状态切换同时使用显式轨迹阶段和传感器反馈。

建议规则：

- `DESCEND` 阶段超过接触力阈值后进入力控制；
- 使用进入阈值与退出阈值构成滞回，避免模式抖动；
- 切换时连续初始化控制器状态，避免积分突变；
- `RETRACT` 阶段退出力控制并恢复完整笛卡尔阻抗；
- 接触丢失时根据当前阶段选择重新搜索或安全回撤。

接触阈值、滞回值和反馈滤波截止频率在实现阶段参数化。

## 9. 传感器标定与补偿

Demo 启动后，在工具悬空且静止时自动标定：

1. 连续采样 `1 s`；
2. 检查末端速度和传感器波动；
3. 计算零偏；
4. 补偿工具自身重力对传感截面的影响；
5. 输出补偿后的外部 wrench。

若标定期间发生运动或接触，则标定失败，禁止进入力控。

系统同时保留通过关节力矩和 Jacobian 反算的末端 wrench，作为诊断数据，不作为第一版主反馈。

## 10. Python API

高层 API 尽量保持厂商 Demo 的使用习惯，但采用清晰的 SI 单位和显式配置。预期接口包括：

```python
robot.set_cartesian_impedance(...)
robot.set_force_control_params(...)
robot.set_force_cmd(force_n=10.0)
robot.execute_chopping_trajectory(...)
robot.stop()
robot.get_wrench()
```

要求：

- 位置单位为米；
- 角度单位为弧度；
- 力单位为牛顿；
- 力矩单位为牛顿米；
- API 对单位、坐标系和正方向给出明确文档；
- 非法参数立即抛出可诊断异常；
- 不直接依赖厂商 `.so`。

## 11. 安全策略

第一版至少包括：

- 最大下探距离：`50 mm`；
- 最大允许接触力：`30 N`；
- 建立接触超时：`2 s`；
- 关节位置限位；
- 关节速度限位；
- actuator 力矩限位；
- 力矩变化率限制；
- IK 失败保护；
- 控制周期超时监测；
- NaN/Inf 检测；
- Viewer 或用户终止后的安全停机。

任一严重保护触发后：

1. 停止继续下压；
2. 清除力控制器积分状态；
3. 在可安全执行时沿工具 Z 轴回撤；
4. 记录故障原因和触发数据；
5. 结束当前 Demo，并返回失败状态。

## 12. Demo 与数据记录

### 12.1 静态恒力 Demo

流程：

1. 移动到砧板上方；
2. 缓慢下探；
3. 检测接触；
4. 建立 `10 N` 目标力；
5. 稳定保持 `5 s`；
6. 安全回撤。

### 12.2 动态剁切 Demo

执行五次参数化的“落刀—恒力—起刀—移位”循环。

### 12.3 可视化与日志

提供 MuJoCo Viewer。终端低频显示：

- 当前轨迹阶段；
- 目标与实测工具 Z 轴力；
- 末端位置误差；
- 控制频率；
- 安全状态。

每次运行写入 CSV，至少包含：

- 时间戳；
- 状态机阶段；
- 目标和实际末端位姿；
- 目标和实际六维 wrench；
- 原始传感器读数；
- 补偿后传感器读数；
- 关节位置、速度和控制力矩；
- 接触状态；
- 安全保护状态。

运行结束生成结果摘要和关键指标。

## 13. 验收标准

### 13.1 功能验收

- 六维传感器输出工具坐标系下的补偿后 wrench；
- 悬空静止时补偿后力接近零；
- 静态恒力 Demo 能稳定保持 `10 N`；
- 动态 Demo 完成五次剁切循环；
- Python API 和命令行均可运行；
- Viewer、CSV 和结果摘要可用；
- 安全保护可通过测试触发。

### 13.2 定量指标

- 静态 `10 N` 恒力稳态误差不超过 `±1 N`；
- 恒力阶段无持续振荡；
- 非接触阶段末端位置 RMSE 不超过 `5 mm`；
- 每次接触峰值不超过 `30 N`；
- 关节力矩不超过模型限制；
- 五次剁切过程中不触发非预期安全保护。

### 13.3 测试范围

单元测试至少覆盖：

- 工具坐标系与世界坐标系变换；
- 六维传感器索引和符号约定；
- 去皮和工具重力补偿；
- Jacobian 与 wrench-to-torque 映射；
- 笛卡尔阻抗控制律；
- 力控制器限幅和抗积分饱和；
- 状态机与接触滞回；
- 安全保护；
- 轨迹插值和参数校验。

集成测试至少覆盖：

- 悬空传感器标定；
- 静态恒力；
- 一次完整剁切循环；
- 五次重复剁切；
- 超力、超时和最大下探距离保护。

## 14. 建议实现阶段

1. 修正基础 MJCF，加入力矩 actuator 和稳定命名；
2. 建立工具、六维传感器和砧板场景；
3. 扩展 MuJoCo runtime，支持状态、Jacobian、传感器和力矩控制；
4. 实现传感器标定、坐标变换及重力补偿；
5. 实现笛卡尔阻抗控制器；
6. 实现工具 Z 轴恒力控制与安全保护；
7. 实现剁切轨迹和状态机；
8. 增加 SDK 风格 Python API；
9. 增加 Viewer、CSV 和结果摘要；
10. 完成单元测试、集成测试和参数调优；
11. 第一版验收后再设计 ROS 2 封装。

## 15. 后续扩展

第一版稳定后可继续扩展：

- 六轴混合力/位控制；
- 关节阻抗模式；
- 水平推切和拉切轨迹；
- 真实刀具和厨具模型；
- 可变刚度与自适应力控；
- ROS 2 service/action 接口；
- 真实机械臂接口适配；
- 厂商运动学结果对照；
- 可破坏或可切割材料模型。

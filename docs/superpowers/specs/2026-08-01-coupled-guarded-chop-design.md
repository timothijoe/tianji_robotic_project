# 双臂耦合猫爪倒手切菜设计

## 目标

把当前“右手完成全部动作后左手才动作”的串行切菜流程改为安全耦合流程。
右刀越过安全高度后，右臂换位与左臂、Wuji Hand 倒手同步执行；下一刀下落前，
左手必须重新合拢并稳定。默认平面场景作为本次实现和演示范围，实体机械臂、
实体 Wuji Hand、ROS 2 硬件发送及物体切分均不在范围内。

## 当前问题

现有状态机依次执行 `CUT_DOWN`、完整的 `KNIFE_UP`、`HAND_OPEN`、
`HAND_SHIFT` 和 `HAND_CLOSE`。任一时刻通常只有一侧目标在变化，因此动作表现为
左右手轮流等待。该设计安全但缺少真实切菜时抬刀、开手和换位并行发生的协同感。

## 方案

采用安全耦合状态机，不引入通用双臂轨迹优化器。每次非末刀切割后的动作分为：

1. `KNIFE_CLEAR`：右刀从接触点抬升至安全高度，左臂与手指保持静止。
2. `COUPLED_OPEN`：右刀继续抬升，Wuji Hand 同步从猫爪姿态张开。
3. `COUPLED_SHIFT`：右刀横移至下一切点上方，左臂同步后退 2 cm，手指保持张开。
4. `COUPLED_CLOSE`：右刀保持在下一切点安全位，Wuji Hand 合拢。
5. `GUARD_SETTLE`：确认左臂及手指速度低于稳定阈值，然后立即开始下一刀。

最后一刀只需完成右刀回升，不执行倒手。现有初始化、5 个切点、从画面右侧向左侧
切割、每次倒手 2 cm、总倒手 8 cm 等行为保持不变。

## 轨迹同步

预规划仍分别产生右刀轨迹、左臂平移轨迹和手指关节轨迹。执行器新增一个小型的
同步轨迹遍历函数：以归一化进度 `[0, 1]` 对同时参与的轨迹取样；轨迹点数不同时，
较短轨迹按进度重采样，而不是执行完后等待。这样配置中的持续时间可以继续控制
动作速度，同时确保协同阶段内确实存在左右目标同时变化的控制周期。

`COUPLED_OPEN` 使用右刀回升的安全高度以上部分与手指开合轨迹；
`COUPLED_SHIFT` 使用右刀横移轨迹与左臂平移轨迹。`COUPLED_CLOSE` 不移动右刀，
以免刀具在左手尚未稳定时提前下降。

## 安全约束

- 刀刃底部未达到规划安全高度时，左臂和手指目标都必须保持不变。
- 只有刀刃处于安全高度以上，才允许双臂目标在同一控制周期变化。
- `CUT_DOWN` 期间左臂和手指必须静止，且稳定互锁已经通过。
- 刀具与护手距离始终不得低于 `0.02 m`。
- 仿真状态必须有限，刀手不得接触；原有接触、穿透和力限制继续生效。
- 任一约束失败时立即进入 `ABORTED`，保留明确失败原因。

预检将覆盖组合后的同步轨迹，而不仅是分别检查单臂轨迹，确保同时运动不会引入
未被串行预检发现的刀手距离风险。

## 状态、记录与可视化

状态枚举增加 `KNIFE_CLEAR`、`COUPLED_OPEN`、`COUPLED_SHIFT`、
`COUPLED_CLOSE` 和 `GUARD_SETTLE`，替代换位过程中的旧串行状态；旧状态不作为
外部稳定 API 保留。每个采样继续记录左右臂及手指速度、刀手距离、安全判定和
目标/实际状态。

Viewer 保留蓝色目标刀轨迹、青色实际刀轨迹、紫色护手轨迹和 5 个切点。
右上角阶段文本显示新的耦合状态，使用户能直接判断左右手是否正在协同换位。

## 测试与验收

自动测试必须证明：

- 5 刀和 4 次倒手均完成，总倒手距离为 `0.08 m`。
- 每次倒手都存在右臂与左臂或手指目标同时变化的采样点。
- `CUT_DOWN` 期间左臂和手指保持静止。
- 左手首次运动前，刀刃已经达到安全高度。
- 同步组合轨迹的最小刀手距离不低于 `0.02 m`，且无刀手接触。
- Viewer 阶段文本能够显示耦合状态。
- 默认启动脚本仍能打开平面场景并成功结束。

最终进行无窗口回归测试和一次真实 Viewer 演示，对比串行版本应明显减少交替等待，
并能观察到右刀换位与左手倒手同步发生。

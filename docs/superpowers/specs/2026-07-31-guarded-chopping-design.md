# 双臂猫爪倒手切菜设计

日期：2026-07-31  
阶段：A（确定性状态机）；阶段 C 仅预留接口

## 目标

在 MuJoCo 中演示双臂配合切菜：右臂持刀对固定方块重复五次下切，左臂和
Wuji Hand 以猫爪姿态按住方块，并在每次抬刀后沿切菜方向后退 0.02 m。
方块不需要被切开，也不得被推动或抓起。

本功能只作用于仿真。现有 `line-chop`、抓取放置、ROS2 桥接和实体机器人
代码保持独立。

## 场景

- 方块固定在 chopping board 上，作为不可切分的蔬菜代理。
- 抓取放置任务使用的两个灰色支撑台不出现在本任务视图中。
- 右臂保留当前刀具安装和已验证的水平刀刃姿态。
- 左手从刀具另一侧接近方块：四指半握，指尖内收，拇指藏在后方，以靠近
  刀面的第二指节作为护手参考点。
- 刀面与护手参考点的最小安全距离为 0.02 m。

## 动作状态机

任务使用确定性双臂状态机：

1. `INITIALIZE`：重置仿真并加载双臂任务初始位。
2. `GUARD_READY`：左臂到达方块侧面，Wuji Hand 闭合到猫爪目标；右刀位于
   第一刀上方。
3. `CUT_DOWN`：左手和方块保持静止，右刀垂直下降到方块上表面附近。
4. `KNIFE_UP`：右刀沿原路径抬回安全高度。
5. `HAND_SHIFT`：只有刀达到安全高度后，左臂才沿切菜方向后退 0.02 m。
6. 对五刀重复步骤 3–5；第五刀后不再执行多余倒手。
7. `COMPLETE`：保持最终姿态约 10 秒供观察。
8. `ABORTED`：任一安全条件或轨迹条件失败时，保持双臂当前位置目标并停止
   状态推进。

预期结果是五次下切和四次 0.02 m 倒手，总倒手距离 0.08 m。

## 软件边界

新增独立的 `guarded-chop` 任务，不把双臂逻辑塞入现有 `line-chop`：

- 右刀轨迹生成器复用现有刀具标记、姿态和上下切轨迹约束。
- 左手姿态模块保存 20 关节猫爪目标，并暴露护手参考点。
- 左臂轨迹生成器计算猫爪就位和四段 0.02 m 笛卡尔倒手轨迹。
- `SafetyCoordinator` 根据当前阶段、刀具高度、左右手运动许可和刀手距离
  返回允许/拒绝。阶段 A 使用确定性规则。
- 双臂任务状态机发送左右臂独立位置目标，并统一处理 abort。

`SafetyCoordinator` 是阶段 C 的扩展点。后续可在不改变状态机调用接口的前提
下加入实时接触、跟踪误差、动态恢复和双臂同步急停。本轮不实现导纳控制或
实体机发送。

## 数据与安全规则

每个控制周期记录：时间、刀数、阶段、左右臂目标与实际关节、刀刃参考点、
左手护手参考点、刀手距离、刀具高度和安全许可。

安全规则为：

- `CUT_DOWN` 期间左臂和手指目标必须保持不变。
- `HAND_SHIFT` 期间右臂目标必须保持在抬刀位。
- 未达到安全抬刀高度时拒绝左手倒手。
- 左手未完成倒手或正在运动时拒绝下切。
- 刀面到护手参考点的距离小于 0.02 m 时立即 abort。
- IK 失败、关节越界、非有限 MuJoCo 状态或明显轨迹跳变时立即 abort。
- 固定方块的位姿在任务前后必须保持不变。

第一版用几何距离做刀手安全验收，不让刀具和手部发生接触。猫爪与方块允许
轻触，但不依赖接触力闭环。

## 可视化与命令行

新增 `twin-sim guarded-chop` 命令，支持 `--headless`、正常 Viewer 播放和
可配置结束保留时间。

Viewer 标记：

- 蓝色：右刀规划轨迹；
- 青色：右刀实际轨迹；
- 紫色：左手护手参考点实际轨迹；
- 黄色：每刀对应的左手目标位置。

Viewer overlay 显示当前刀数、阶段、最小刀手距离和 `cut_allowed`。默认速度
以清楚但不拖沓为准，任务结束后保留约 10 秒。

## 验收与测试

自动验收必须证明：

- 完成五刀和四次倒手；
- 每次倒手的目标位移为 0.02 m，总位移为 0.08 m；
- 刀下降时左手静止，左手移动时刀保持在安全高度；
- 全过程刀手距离不小于 0.02 m；
- 猫爪关节目标在倒手过程中保持不变；
- 固定方块位姿不变；
- 左右臂目标与实际状态有限且未越界；
- Viewer 轨迹颜色和 overlay 数据正确；
- 非法刀手距离、IK 失败和状态异常会进入 `ABORTED`；
- 全量既有测试和实体机保护文件哈希继续通过。

无窗口 CLI 输出成功状态、完成刀数、倒手次数、总倒手距离、最小刀手距离和
失败原因。可视化验收需能清楚看到“下切—抬刀—左手后退”的交替节奏。

## 非目标

- 不切分或变形方块；
- 不由左手推动方块；
- 不实现刀面接触左手指关节；
- 不实现导纳、力控或阶段 C 的动态恢复；
- 不向实体机械臂或实体 Wuji Hand 发送命令。

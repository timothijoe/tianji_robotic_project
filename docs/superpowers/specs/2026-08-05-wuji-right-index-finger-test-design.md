# Wuji 右手食指 MCP 安全测试设计

## 目标

提供一个独立的命令行脚本，用于验证已固定的 Wuji 右手能否通过官方
`wujihandpy` SDK 做一次低幅度食指 MCP 往返运动。它不控制天机机械臂、
不启动 ROS 2，也不复用仿真轨迹。

## 范围与接口

新增 `scripts/test_wuji_right_index_mcp.py`，使用
`.venv-wujihand/bin/python` 运行：

```bash
.venv-wujihand/bin/python scripts/test_wuji_right_index_mcp.py \
  --serial-number 365939643134
```

该命令是 dry-run：只读取并打印诊断信息。只有显式传入 `--execute` 才能
发送运动命令。脚本固定操作官方 SDK 的 `finger(1).joint(0)`，即食指 MCP。

## 运动策略

预检通过后，脚本读取当前实际角度与设备声明的上下限。它把当前角度作为
中心，并在限位内规划 `-0.05 rad → +0.05 rad → 当前角度` 的单次往返。
每个目标之间暂停一个短的、固定时长的观察窗口。脚本不修改 effort limit、
控制模式或其他 19 个轴的目标。

## 安全门

开始前必须同时满足：

- SDK 按指定 USB 序列号连接，且固件手性为右手；
- 全部 20 轴错误码均为零；
- 全部关节温度不高于 40°C；
- 当前角度、限位与目标均为有限数；
- 目标到各限位保留至少 0.01 rad 裕量。

任何预检失败、SDK 通信异常或运动阶段错误码出现时，脚本立即停止后续
写入，最终都调用 `write_joint_enabled(False)` 失能整手。没有提供跳过温度
或错误码检查的命令行选项。

## 输出与成功条件

脚本打印设备序列号、固件、手性、电压、最大温度、食指 MCP 的起点与
三个计划目标。dry-run 成功表示可安全规划但未运动；`--execute` 成功表示
三个目标都写入完成且结束清理已执行。执行前的温度或错误码失败必须返回
非零且不使能任何关节。

## 测试

将纯规划与预检逻辑提取为可单元测试函数，使用模拟 SDK 覆盖：正常规划、
过温拒绝、错误码拒绝、非右手拒绝、限位不足拒绝，以及异常时的失能清理。
硬件运行只在操作者显式执行 `--execute` 后发生。

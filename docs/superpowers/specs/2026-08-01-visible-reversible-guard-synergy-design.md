# 可见且可逆的猫爪倒手协同设计

## 背景与目标

现有平面切菜演示已经按两刀循环运行：第 1、3 刀后左臂保持不动、手指回缩；第 2、4
刀后左臂回退、手指同步舒张。录制数据表明中央指最大单关节变化约 25°，但关键帧近景
对比和用户 Viewer 观察都证明手指外轮廓变化仍不明显。原因是当前离线标定以单关节角度
和指垫终点为主要目标，多个关节的补偿运动把可见形变抵消了。

本轮继续采用方案 A 的固定离线标定，不引入在线手部 IK。首要目标是在正常全景 Viewer
中清楚看到手指回缩和舒张；两段几何运动严格对称是次要目标，能够满足则保留，但不能以
牺牲可见度为代价。

## 方案选择

采用一对可逆手势和同一条 minimum-jerk 轨迹。`GUARD_RELAXED_RAD` 到新的
`GUARD_RETRACTED_RAD` 用于回缩，舒张直接使用同一轨迹的反向序列。这样两段持续时间、
进度曲线和目标关节幅度天然一致，不为奇数、偶数倒手维护两套关键帧。

不采用以下方案：

- 不分别手工设计回缩与舒张动作，因为两套轨迹容易产生不同节奏和机械感；
- 不用近景相机、marker 或降低回放速度掩盖姿态问题；这些只能辅助观察，不能替代真实
  手指轮廓变化；
- 不实现在线 20 关节 IK，本轮仍要求运行时确定、可预检、可重复。

## 离线标定目标

标定不再以“某个关节达到 25°”作为主要可见度代理，而是在当前 MuJoCo 手模型上测量
放松和回缩端点之间的真实几何变化。优化及测试至少覆盖：

- `finger3` 的可见中间指节位置或指节连杆方向变化，中央指承担主要形变；
- `finger2`、`finger4`、`finger5` 以逐级减弱的方式自然跟随；
- 手指整体轮廓不能通过近端、远端关节反向旋转而基本抵消；
- 拇指继续保持内藏，不用张开拇指制造视觉幅度；
- 所有关节目标位于 actuator 范围内，姿态本身无刀手接触。

优先选择能产生明显近端/中间指节位移和连杆方向变化的候选，而不是仅让末端关节大幅
旋转。标定程序只作为离线诊断；最终运行时代码仍保存一组固定关节常量。

## 运动与耦合时序

平面模式保持既有状态机：

1. 第 1、3 刀完成并稳定后，右刀低位锁定，左臂 7 关节目标不变；手指在 2.5 秒内从
   放松姿态运动到回缩姿态。
2. 第 2、4 刀完成并稳定后，右刀低位锁定；左臂掌心约回退 4 cm，手指在同一个 2.5
   秒窗口内沿完全相反的关节轨迹恢复放松姿态。
3. 两段使用相同 sample 数和 minimum-jerk progress。对任意归一化时刻 `u`，舒张的
   手指目标等于回缩轨迹在 `1-u` 时的目标，允许位置伺服产生小量实际跟踪误差。
4. 右刀只在左臂和手指稳定后抬起并移动到下一切点。

object 模式以及实体机械臂、ROS 2、Wuji Hand SDK 路径均不修改。

## 几何与安全约束

视觉效果为主，但不放宽任何安全条件：

- 刀片到全部手部碰撞代理的距离始终不低于 2 cm；
- 刀片与手部真实接触数始终为零；
- 右刀低位时右臂目标锁定并继续检查实际速度；
- 右刀下切时左臂和手指必须稳定；
- 手指关节目标、速度和数值状态必须有效。

指垫相对掌心的回缩与舒张位移尽量大小相等、方向相反。规划世界坐标仍以单次约 2 cm、
四次约 8 cm 为目标；若新的可见姿态改变指垫相对掌心位移，则离线重新计算偶数周期的
左臂回退距离，使世界倒手量保持在现有运行期容差内。不能通过放宽安全距离或制造碰撞来
满足位移目标。

## 自动测试

新增或调整测试以验证：

- 舒张关节轨迹逐样本等于回缩轨迹的严格反向序列；
- 两段均为 2.5 秒并具有相同 sample 数和 minimum-jerk 进度；
- 中央指的可见中间指节位移和连杆方向变化达到离线基准，外侧手指分层跟随；
- 近端与远端关节不能通过反向补偿使中央指轮廓变化退化到旧版本水平；
- 固定掌心下的指垫位移、非目标漂移、执行器范围和无碰撞检查通过；
- 四次实际世界倒手保持向同一方向推进，累计约 8 cm；
- 全部既有刀手距离、接触、速度互锁、录制回放和 object 模式测试继续通过。

测试中的“可见度”使用模型几何量而非截图像素或人工主观角度，保证自动回归稳定；最终
仍必须由用户在正常全景 2× Viewer 中确认。

## 人工验收

最终生成新的默认录制并进行 2× 回放。验收重点为：

- 无需手动缩放镜头即可看到第 1、3 刀后的手指明显回缩；
- 第 2、4 刀时能同时看到左臂回退和手指舒张；
- 回缩与舒张的视觉幅度和节奏接近，像同一动作正放与倒放；
- 中央指主导、外侧指自然跟随，不出现整手刻意开合；
- 左右手耦合顺序和刀具动作维持当前已认可版本。

若正常全景仍无法辨认手指轮廓变化，本轮不能仅凭关节角数据宣告完成；需要返回离线姿态
标定继续调整。近景图只用于诊断，不作为替代验收。

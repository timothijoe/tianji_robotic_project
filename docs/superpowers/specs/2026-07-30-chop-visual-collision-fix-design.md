# 切菜演示碰撞与可视化修正设计

日期：2026-07-30

## 问题与证据

慢速演示中机械臂的实际关节变化为 `0.12–0.53 rad`，说明位置执行器确实在运动；
但当前正面视角遮挡了主要的竖直位移。更严重的是，任务用
`right_blade_edge_bot` 作为接触基准，而该 site 不在刀片碰撞体的真实最低边缘。
诊断运行测得案板顶面为 `z=0.230 m`，接触阶段刀片碰撞体最低点为
`z=0.173 m`，即几何穿入约 `57 mm`。

## 设计

1. 刀片保留视觉 mesh，但使用与真实刀刃位置一致的薄碰撞几何；接触基准 site
   放在碰撞刀刃的最低边缘。
2. 切菜预检根据这个真实刀刃 site 生成安全点和接触点。配置的
   `penetration_m` 仍表示允许的目标压入量，默认保持 `3 mm`。
3. 增加几何回归测试：初始姿态无刀片—案板接触；接触目标处碰撞刀刃相对案板
   的穿入不得超过 `5 mm`。
4. Viewer 演示使用侧前方固定相机，使竖直运动和刀刃—案板间隙同时可见。
5. `chop --slow` 使用 5 秒起始停留、3 秒接近、3 秒下降、1 秒接触停留、
   3 秒回升和 8 秒结束停留。Headless 模式不等待墙钟时间。

## 边界

- 不改变实体机器人文件。
- 不改变位置控制架构，不加入阻抗或力反馈控制。
- 接触力仍只用于记录和警告。
- 修复后必须通过全量仿真测试、受保护文件哈希检查和一次完整 GUI 重播。

# 运行与排障手册

更新日期：2026-08-02。适用于“右手 Wuji Glove 的 Studio MCAP → 左手 Wuji Hand 的 MuJoCo 可视化”。

## 最短操作流程

1. 用 Wuji Studio 连接右手手套，在 Studio 中录制 MCAP；录制完成后停止录制并关闭 Studio 或至少断开手套会话。
2. 打开一键脚本：

   ```text
   /home/zhoutong/catkin_robotic_ws/august_ws/wuji-technology/wuji-glove-recorder/visualize_right_glove_to_left.sh
   ```

3. 修改顶部唯一需要修改的配置项：

   ```sh
   DEFAULT_MCAP_PATH="/绝对路径/你的录制文件.mcap"
   ```

4. 在终端运行：

   ```bash
   cd /home/zhoutong/catkin_robotic_ws/august_ws/wuji-technology/wuji-glove-recorder
   sh visualize_right_glove_to_left.sh
   ```

5. 脚本会在原 MCAP 旁边生成：

   ```text
   <原文件名>_right_to_left_wuji_hand.npz
   <原文件名>_right_to_left_wuji_hand.mcap
   ```

   随后自动打开 MuJoCo 左手模型。

## MuJoCo 操作

| 按键 | 作用 |
| --- | --- |
| `Space` | 播放 / 暂停 |
| `←` / `→` | 暂停时前后逐帧 |
| `R` | 回到第一帧 |
| `+` / `-` | 加快 / 减慢播放速度 |
| `Esc` | 关闭窗口 |

关闭窗口后脚本进程会结束。该窗口仅做离线仿真，**不会运动实体手**。

## 先检查、不生成文件

如想确认所选路径和输出文件名，可以运行：

```bash
cd /home/zhoutong/catkin_robotic_ws/august_ws/wuji-technology/wuji-glove-recorder
sh visualize_right_glove_to_left.sh --dry-run
```

这只会打印三个处理步骤，不会写文件、不会打开 MuJoCo。

## 常见问题

### 1. `set: Illegal option -o pipefail`

这是旧版本脚本只能以 Bash 运行时出现的错误。当前版本已经改为 POSIX `sh` 兼容语法。确认运行的是本工程的最新版脚本：

```bash
sh /home/zhoutong/catkin_robotic_ws/august_ws/wuji-technology/wuji-glove-recorder/visualize_right_glove_to_left.sh --dry-run
```

### 2. `MCAP file not found`

`DEFAULT_MCAP_PATH` 路径错误，或 Studio 录制文件已移动。请在文件管理器中复制该 `.mcap` 的完整路径，替换脚本顶部的值。路径中有空格也可以，前提是保留外层双引号。

### 3. `Expected a .mcap recording`

配置项指向的不是 `.mcap` 文件。请选择 Studio 实际录制生成的 MCAP，而不是转换后生成的 `.npz`。

### 4. MuJoCo 没有出现、终端提示 Python 环境缺失

脚本内部依赖以下两个固定环境：

```text
/home/zhoutong/catkin_robotic_ws/august_ws/wuji-teleop-venv/bin/python
/home/zhoutong/catkin_robotic_ws/august_ws/tianji_robotic_project/.venv/bin/python
```

先检查两个文件是否仍存在且可执行；如果移动了工程目录，应修改脚本顶部的 `SDK_PYTHON`、`MUJOCO_PYTHON`。

### 5. Studio 看不到生成的左手手模型

生成的 `.mcap` 是标准 `/joint_states` 数据。Studio 的 Hand Skeleton 可视化针对手套骨架，当前不会据此自动生成左手模型。这是已知界面能力限制，不代表关节数据转换失败；请用 MuJoCo 查看左手动作。

### 6. MuJoCo 指尖关节看上去弯得比手套显示更明显

先确认文件名包含 `_right_to_left_wuji_hand`。该版本已经对右手输入执行 Y 轴镜像。未包含这一后缀的早期 `*_left_wuji_hand.*` 文件没有镜像，容易使食指到小指末端关节接近上限。

此外，Studio 画的是手套骨架，MuJoCo 画的是机械手模型；两者连杆长度和关节形态不同，应比较动作趋势而非外观逐像素一致。

### 7. 手套连接显示 `Session already exists`

同一手套被 Wuji Studio 和独立 SDK 客户端同时占用。关闭其中一方或停止其连接后重试。Studio 录制与当前 MCAP→MuJoCo 离线脚本不冲突，因为后者不连接手套。

## 安全边界

- 本一键脚本只读取 MCAP、生成本地文件并启动 MuJoCo；不导入 ROS 控制节点，也不向实体手发送命令。
- 不要在 ROS 驱动已控制实体手时，再用 SDK 对同一实体手直接下发命令。
- 若下一步开发实时遥操作，应先在 MuJoCo 验证，再加限位、速率限制、急停和人工监看，最后以小幅低速动作接入实体手。

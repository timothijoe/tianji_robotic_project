# Wuji Glove Recorder 设计

## 目标

提供一个很小的桌面程序，采集右手 Wuji Glove 的手部骨骼数据，用于后续离线分析和右手套到左机械手的映射验证。

## 范围

- 使用已验证的 UDP 端点 `192.168.10.151:50001` 连接右手手套。
- 提供“开始记录”和“停止并保存”两个按钮。
- 录制期间只订阅 `hand_skeleton`，不发布 ROS 消息，不连接或控制机械手。
- 显示连接状态、已记录帧数和录制时长。
- 保存为单个压缩 `.npz` 文件，包含：
  - `timestamps_ns`：每帧单调时钟时间戳，形状 `(N,)`；
  - `keypoints_m`：21 个骨骼关键点的米制坐标，形状 `(N, 21, 3)`；
  - `metadata`：设备端点、序列号、左右手标识和采样信息。
- 文件默认保存到工具目录下的 `recordings/`，文件名包含本地开始时间。

## 非目标

- 不进行手套标定、设备 IP/端口或固件修改。
- 不记录或命令左机械手关节。
- 不做实时 retargeting 或训练模型。
- 不提供浏览器服务、数据库或复杂项目结构。

## 结构

`glove_recorder.py` 为唯一可执行入口，包含三个小职责：

1. `GloveSession`：连接、订阅、断开 SDK 设备。
2. `Recording`：收集并校验每帧的 `21 x 3` 坐标，保存 NPZ。
3. `RecorderApp`：Tkinter UI；采样在后台线程中运行，所有控件更新回到 UI 线程。

## 数据流与安全行为

`Wuji Glove -> Wuji SDK hand_skeleton -> 后台采样线程 -> 内存缓冲 -> NPZ`。

点击开始前成功连接才允许开始。停止后写出文件并显示绝对路径。连接断开或连续未收到有效帧时停止录制、保留已采集数据并把原因显示在窗口。程序退出时会停止线程并断开手套。

不会导入 ROS 客户端库，也不会发布任何机械手命令。

## 验证

- 单元测试覆盖：帧形状校验、空录制拒绝保存、NPZ 内容与元数据。
- 在当前右手套上手动验证：开始后张握手指至少 5 秒，停止后产生 NPZ；加载文件确认形状为 `(N, 21, 3)` 且 `N > 0`。
